Molan Chat documentation

Molan Chat is the personal messaging application. Its main navigation is intentionally simple: Chats, Settings and Updates. These guides explain the purpose of each area; open the app to access its current interface.

Product guide · Links open the current application
Feature guides are maintained against verified product behaviour. Where a feature is still being developed, this page identifies it as a work in progress rather than describing it as already available.

Chats

The Chats area is the starting point for conversations and discovering people or groups. Use the in-app search and quick-create controls to find or start conversations.
